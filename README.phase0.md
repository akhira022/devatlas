# DEV ATLAS

> Interactive Knowledge Map for Developers — เรียนรู้โลก Developer ผ่านคำอธิบาย, Visualization, Simulation และ Knowledge Map

## Vision

ช่วยให้ Developer มือใหม่และระดับกลาง **เข้าใจเทคโนโลยีเป็นภาพรวม** ไม่ใช่แค่จำศัพท์แยกกันตาม Tutorial

## Core Loop

```
ไม่เข้าใจคำ → Search → อ่าน Concept → ดู Flow → ลองเล่น → ดูความเชื่อมโยง → เข้าใจภาพรวม
```

## Tech Stack (Planned)

- **Frontend:** Next.js, TypeScript, Tailwind CSS, shadcn/ui
- **Animation:** Framer Motion
- **Diagrams:** React Flow
- **Backend (Post-MVP):** Supabase (PostgreSQL, Auth, Storage)
